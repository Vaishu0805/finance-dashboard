# Finance Dashboard

A responsive financial dashboard built using React.

## Features
- Add, edit, delete transactions
- Role-based UI (Admin / Viewer)
- Charts (Pie & Line)
- Dark mode
- Responsive design
- Local storage persistence

## Tech Stack
- React (Vite)
- JavaScript
- Recharts
- CSS
